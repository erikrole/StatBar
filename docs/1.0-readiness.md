# StatBar 1.0 readiness

Target: **1.0.0 (build 5)**, Apple Silicon, macOS 27 or later.
Prepared October 27, 2026. This is a release candidate preparation record;
1.0 has not been published or installed over the signed app in Applications.

## Scope

Keep the existing monitoring feature set and compact layout. Fix the concurrent
launch race, make the startup grace period asynchronous, isolate diagnostics from
updates and Login Items, restore repeatable idle profiling, and expose the version
in Settings. Keep the pinned AppUpdater revision and its host termination guards.

## Acceptance still requiring real hardware or installed-app testing

- Actual display sleep/wake and resumed readings; controlled-reader tests cover
  cancellation and stale-baseline handling, not physical sleep.
- Ethernet/Wi-Fi transitions and GlobalProtect connection changes.
- Removable media that stalls while a read is in flight.
- Longer idle and on-battery sessions; short CPU/RSS measurements do not establish
  battery impact or long-term leak freedom.
- An installed 0.1.3 → 1.0 update, relaunch, and recovery behavior. Preparing a signed
  ZIP and preserving updater guards does not establish this installed transition.
